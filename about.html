About me

Developer & data engineer

I'm Nkosikhona Dlamini — a developer who thinks in systems, builds with intention, and cares about how data moves through the world. I work at the intersection of software engineering and data: turning raw information into reliable pipelines, models, and tools that teams can trust.

What I know

My core stack spans data engineering, cloud platforms, and the engineering practices that keep pipelines maintainable over time.

  • Data engineering & ETL: SQL, Python, data modeling, pipeline design, PostgreSQL, Docker, and database management
  • Systems & tooling: Bash, Linux (Debian/Ubuntu, Fedora/RHEL, openSUSE), Boto3, and API integration
  • Cloud & big data: AWS, Azure, GCP, data warehousing, Spark, Airflow, and modern big-data tooling
  • Engineering discipline: CI/CD for data workflows, Git, issue boards, data governance, unit testing, and integration testing

What I do

I design and build data systems — from ingestion and transformation through to delivery. That means ETL pipelines, warehouse structures, automation around data quality, and the glue code that connects services, APIs, and storage.

Outside pure data work, I write, explore ideas in public, and keep coming back to the terminal — not out of nostalgia, but because clear tools make clear thinking easier.

How I do it

I start with constraints: what must be true, what can fail, and what needs to be auditable. Then I build in layers — small, testable pieces with explicit contracts between them. Pipelines get version control, tests, and review the same way application code does. When something breaks, I read the error instead of clicking around it.

I prefer tools that stay out of the way once learned, environments I can reproduce, and documentation that explains why, not just what. Good data work is invisible when it runs and obvious when it doesn't.

Background

I completed my high school diploma at Matthew Goniwe Memorial High School (2011–2015). Since then I've focused on building practical engineering skills across data platforms, cloud infrastructure, and software craft.
